# Security

This static prototype contains only fictional data and has no account or server-side storage. Do not deploy it as a private family database or place confidential files in its public directory.

Do not report security issues with personal data, credentials or private family exports in a public issue. Until a private reporting channel is configured, report only a non-sensitive description and request a private contact channel. Production authentication, authorization, upload handling and backup restoration are release gates, not implemented features.
